# animations

Put animation files (GIF, animated WebP, PNG) in sub-folders here. See the main README for which folder does what.
The `alert` folder holds the alert animation and its sound (WAV, MP3, WMA or M4A).

The files themselves aren't part of the repository. Run the app and accept the starter-pack download,
or run `YierBubuPet.exe --starter-pack animations`.
